# Zaman Studio

A modern single-page portfolio website for a videography and gimbal specialist based in Pakistan. The site showcases services, recent shoots, pricing, client testimonials, a promo reel, and a WhatsApp booking form for inquiries.

## Project overview

This project is built as a lightweight static website using plain HTML, CSS, and JavaScript. It is designed to be fast, easy to customize, and easy to host on any static hosting provider.

## Files in this project

- [index.html](index.html) — main page structure and content
- [style.css](style.css) — visual design, layout, and responsive styles
- [script.js](script.js) — simple interactions, gallery controls, and WhatsApp form behavior
- [assets/](assets/) — images and video files used across the site

## Features

- Hero section with cinematic styling
- About section highlighting videography and gimbal work
- Recent shoots and portfolio gallery
- Embedded video sections and promo reel
- Pricing package cards
- Client testimonials
- Contact section with WhatsApp inquiry form
- Responsive layout for desktop and mobile devices

## Local setup

Because this is a static website, you can run it in either of these ways:

1. Open [index.html](index.html) directly in a browser.
2. Or serve the folder locally using a simple web server, for example:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Customization

You can update the project by editing:

- Business name, contact number, and copy in [index.html](index.html)
- Colors, spacing, typography, and layout in [style.css](style.css)
- Scroll/gallery behaviors and form submission in [script.js](script.js)

## Notes

- The site is designed for a videography business and uses WhatsApp as the primary booking/contact method.
- Media files in [assets/](assets/) should be kept in the same relative paths referenced by [index.html](index.html).
